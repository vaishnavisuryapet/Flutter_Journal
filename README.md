# Journal UI — Flutter

A simple Flutter journal app with:

- Login page with form validation
- Home page showing journal entries
- Add/edit journal entries
- Mood selection: Happy, Calm, Neutral, Sad, Angry
- Mood analytics with entry counts and percentages
- Local storage using shared_preferences

## Run in Zapp.run

1. Open https://zapp.run
2. Create a new Flutter project.
3. Replace the project files with the files in this repository.
4. Run the project.

## Tech used

- Flutter
- Dart
- Material 3
- shared_preferences
